## 五、 结构规范与维护指引 (Structural Guidelines & Invariance)

为了确保本汉化语料能够 100% 稳定用于 Galgame 封包注入、补丁制作与跨版本迁移，所有文本改动必须严格遵守以下工程守则：

1. **行数与格式守恒**：
   - 文本行严格为 `110,622` 行，杜绝任何换行断行、空白行丢失或合并。
   - 绝大多数文本行为制表符分隔：`<scene_id>#<index>\t<text>`。个别全屏展示叙事行（如《天使之咆哮》部分片段）不含制表符，必须与日文原版保持严格对称。
2. **说话人标签守恒**：
   - 台词行前置的 `@角色名@` 为游戏引擎的语音及立绘绑定钩子，严禁擅自增删或将特定系统绑定名翻译丢失。
3. **引擎控制符守恒**：
   - 加粗控制符：`$[...$]`、`[$b...$]` 必须成对出现，内部文字可翻译，但闭合标签不可破坏。
   - 分歧选项符：`$d`（如 `扣下扳机$d不扣扳机`）严格用于剧情分支跳转。
   - 演出效果标记：如 `$S(...)`、`$A(...)` 等，原样绝对保留。
