# Grisaia Text Localization & Polishing (灰色系列全文本汉化校对与润色)

## Overview
本工作区存放了 Frontwing 灰色系列（Grisaia）Galgame 的全文本提取与汉化文本：
- `ALL_TEXT.txt`: 日文原版提取文本（共 110,622 行）
- `ALL_TEXT_cn.txt`: 对应中文汉化文本（共 110,622 行）

## 目标与规范
1. 对齐校验与原意校对：依据日文原文严谨校对中文译文，纠正机翻错误、逻辑颠倒、漏译及语义偏差。
2. 专有名词与系列梗：遵循《灰色的果实》《灰色的迷宫》《灰色的乐园》官方及公认译名设定，精准还原角色特定口吻、军事黑话与捏他/梗。
3. 去 AI 味与自然润色：消除生硬直译、AI 常见句式与词汇，确保台词生动自然、符合 Galgame 演出节奏。
4. 控制符与结构守恒：严格保持每一行的结构 ID（如 `grisaia1/ama_001#00370`）、人物标签（如 `@雄二@`、`@由美子@`）及控制符不变。
